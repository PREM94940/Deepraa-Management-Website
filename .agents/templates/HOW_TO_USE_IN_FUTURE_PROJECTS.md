# Master Guide: How to Deploy Enterprise Governance OS v2

This directory contains the universal templates to instantly transform any new project into an autonomous, self-driving, highly-governed enterprise system.

## Step 1: Initialize the Project
1. Create a new folder for your project (e.g., `D:\My New Startup`).
2. Copy ALL `.md` files from this folder (`D:\Common Skills to Manage\Enterprise_Governance_OS_v2`) into the root of your new project directory.

## Step 2: Prime the Architect (ChatGPT)
Open ChatGPT and paste the following prompt:
> "You are the High-Level Architect AI for this project operating under Enterprise Governance OS v2. Your partner is the Antigravity IDE AI, which handles local file execution. 
> 1. Use the **Tiered Routing Engine**: Explicitly state if your plan belongs in the Fast-Lane (UI only) or Slow-Lane (Core logic).
> 2. ALWAYS end your response with a markdown block labeled 'PASTE THIS INTO AI_BRIDGE.md' containing the blueprint and setting the Handoff Token to 'Antigravity IDE'."

## Step 3: Prime the Executor (Antigravity IDE)
Open Antigravity IDE and paste the following prompt:
> "We are initializing Enterprise Governance OS v2. Read the `IDENTITY.md`, `MEMORY.md`, `SKILLS.md`, `AGENT_SWARM.md`, `TIERED_PIPELINE.md`, and `DETERMINISTIC_EVIDENCE.md` files in the root directory to understand your guardrails. Then, read `AI_BRIDGE.md` to see the Architect's blueprint. Execute the next task. Remember: You cannot pass a gate without generating Deterministic Terminal Evidence."

## Step 4: The Loop
1. Ask ChatGPT for a feature.
2. Copy its blueprint into `AI_BRIDGE.md`.
3. Tell Antigravity: "Execute `AI_BRIDGE.md`".
4. Antigravity writes the code, runs the tests (generating deterministic proof), pastes the terminal logs back into `AI_BRIDGE.md`, and hands it back to ChatGPT.
